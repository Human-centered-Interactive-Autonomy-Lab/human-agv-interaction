# Behavioral Clustering

This folder contains the script used to perform clustering on behavioral data in the human–AGV interaction study.

## File Description

### run_clustering_on_behavioral_data.R
This script performs clustering on behavioral features extracted from the dataset.  
It applies dimensionality reduction and clustering techniques (e.g., MFPCA and k-means or hierarchical clustering) to identify distinct behavioral patterns among participants.

## Notes
- The clustering results are used to identify behavioral groups in the study.
- These clusters are later used for statistical analysis and visualization in the analysis pipeline.
