# Behavioral Trust Analysis

This folder contains scripts for post-hoc statistical analysis and visualization of behavioral clustering results in the human–AGV interaction study.

## File Descriptions

### post_hoc_analysis.py
This script performs post-hoc statistical analysis and reports the statistical results.  
It includes comparisons between clusters using appropriate statistical tests and effect size calculations.

### post_hoc_analysis_utils.py
This file contains helper functions used in `post_hoc_analysis.py`.  
It provides reusable utilities for statistical computations and data handling.

### visualize_behavioral_cluster_effects.py
This script is responsible for generating all visualizations related to behavioral clustering.  
It produces figures and plots that illustrate the effects and differences between clusters.

### visual_analysis_utils.py
This file contains helper functions used for visualization.  
It provides reusable plotting utilities and formatting functions used by the visualization scripts.

## Notes
- Post-hoc analysis scripts focus on statistical validation of clustering results.
- Visualization scripts are used to interpret and present the results clearly.
