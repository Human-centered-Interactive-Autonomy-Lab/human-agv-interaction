# Subjective Clustering

This folder contains the script used to perform clustering on subjective (self-reported) data in the human–AGV interaction study.

## File Description

### run_clustering_on_subjective_data.R
This script performs clustering on subjective measures such as trust, comfort, and safety ratings.  
It applies dimensionality reduction and clustering techniques to group participants based on their reported experiences.

## Notes
- The clustering results reflect patterns in participants’ subjective perceptions.
- These clusters are used for comparison with behavioral clustering results and further statistical analysis.
