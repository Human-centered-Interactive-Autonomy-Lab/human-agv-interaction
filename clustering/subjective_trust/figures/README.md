# Subjective Trust Figures

This folder contains all outputs related to subjective clustering, including analysis results and visualizations.

## Folder Structure

### analysis/
This folder contains results related to post-clustering analysis.  
It includes:
- Correlation matrices  
- Statistical summaries  
- Results used to interpret relationships between subjective measures and clusters  

### clustering/
This folder contains outputs generated during the clustering process.  
It includes:
- Silhouette method scores  
- Elbow method results  
- Any intermediate metrics or evaluations used to determine the number of clusters  

## Files

### cluster_1_representative.gif  
### cluster_2_representative.gif  
These files provide visual representations of the identified subjective clusters.  
They illustrate typical patterns in participants’ reported experiences (e.g., trust, comfort, safety).

## Notes
- All clustering-related visual outputs are saved in this folder.
- The analysis subfolder focuses on interpreting clustering results.
- The clustering subfolder contains diagnostic metrics used to validate clustering choices.
